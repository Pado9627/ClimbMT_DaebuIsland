# 대부도 1박 2일 여행 일정표

모바일에서 보기 좋은 여행 일정표입니다.

## GitHub Pages로 공개하기

1. GitHub에서 새 Repository를 만듭니다.
2. `index.html` 파일을 업로드합니다.
3. Repository의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 선택합니다.
4. Branch는 `main`, 폴더는 `/ (root)`로 설정합니다.
5. 잠시 후 생성된 GitHub Pages 주소로 접속하면 됩니다.

장소 버튼은 네이버지도 상호명 검색으로 연결됩니다.
